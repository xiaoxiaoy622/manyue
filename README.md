# 月满西楼 - Douluo Dalu H5 Private Deployment

## 项目说明

本项目是斗罗大陆H5游戏的个人化部署版本，仅包含前端静态资源（HTML / CSS / JavaScript / 图片），**不包含任何后端服务**。所有资源均引用自原始 CDN，部署后即可通过浏览器访问。

**核心特性**：满月加速器 + CDN 智能缓存 + 移动端适配

### 功能特点

| 特性 | 说明 |
|------|------|
| **倍速范围** | 0.5x / 1x / 2x / 5x / 10x / 50x / 100x / **200x**（8档） |
| **月相选择** | 8个月相阶段（朔月→残月），每个阶段对应一首诗句 |
| **卷轴面板** | 金色卷轴展开动画，古风 UI 设计 |
| **持久化** | 支持 localStorage 记住加速设置（「铭记」按钮） |

| 按键 | 功能 |
|------|------|
| `[` / `]` | 切换月相（降低/提高倍速） |

| `P` | 切换持久化（铭记/取消铭记） |

- **点击左上角月亮图标**：展开/关闭控制面板
- **拖拽月亮图标**：移动加速器位置

## CDN 缓存方案

本项目实现了智能 CDN 缓存系统，优先从 CDN 加载资源，利用浏览器 localStorage 缓存，**缓存7天后自动过期**，无需手动更新版本号。

### 工作原理

```
访问流程：
1. 检查 localStorage 缓存（含7天有效期）
   ├─ 命中且未过期 → 直接显示（毫秒级，无网络请求）
   ├─ 缓存已过期(>7天) → 自动清除并重新下载
   └─ 未命中 → 请求 CDN
       ├─ 成功 → 显示 + 存入缓存（7天有效）
       └─ 失败 → 降级到本地 img/ 目录
```

### 自动过期机制

| 场景 | 行为 |
|------|------|
| 首次访问 | 从 CDN 下载 → 存入缓存（7天有效） |
| 7天内访问 | 使用本地缓存（无网络请求） |
| 7天后访问 | 自动清除过期缓存 → 重新从 CDN 下载 |
| CDN 不可用 | 降级到本地 img/ 目录 |

### 控制台命令

| 命令 | 功能 |
|------|------|
| `showCacheStatus()` | 查看缓存状态（数量、大小、已缓存天数、剩余天数） |
| `clearAllCache()` | 清除所有缓存 |
| `refreshCache()` | 强制刷新缓存并重新加载 |
| `forceCdn(true/false)` | 强制使用 CDN 或本地资源 |

### 示例输出

```
// 首次访问（缓存为空）
[CDN] 检测成功，使用 CDN 加载资源
[CDN-Cache] 缓存图片: img/bg.jpg (680 KB) - 7天有效

// 7天内访问（命中缓存）
[CDN-Cache] 命中缓存: img/bg.jpg (剩余6天)

// 7天后访问（缓存过期）
[CDN-Cache] 缓存已过期(>7天)，重新下载: img/bg.jpg
[CDN-Cache] 缓存图片: img/bg.jpg (680 KB) - 7天有效
```
